# 🎵 Music Player

A simple and interactive Music Player web application built using **HTML, CSS, and JavaScript**. It provides a user-friendly interface to play music and control playback directly from the browser.

## ✨ Features

- ▶️ Play and pause songs
- ⏭️ Play the next song
- ⏮️ Play the previous song
- ⏱️ Track playback progress
- 🎚️ Control song progress using the progress bar
- 🔊 Adjust the volume
- 🎨 Clean and user-friendly interface
- 📱 Responsive design (if supported by your implementation)

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and layout
- **JavaScript** – Audio playback controls and interactivity

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Make sure the required audio files are available in the correct folder.
4. Open `index.html` in your browser.
5. Select a song and enjoy listening to music.
